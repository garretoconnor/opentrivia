1. When players join a game with a code, they should be able to buzz in during host mode.

1a. Buzzes should be enabled once the host shows the clue.

1b. The clue should disappear once the first buzz comes in.

2. The server should resolve which player buzzed in first.

3. The first player to buzz should have 35 seconds to submit an answer.

3a. A timer should appear on the connected player's screen showing 30 seconds.

3b. When the timer hits 0, it should turn red and add five seconds.

3c. When the red timer hits 0, the player loses points equal to the clue's value.

4. The host should be able to mark a player's answer correct or incorrect.

5. If the first player to buzz in fails to answer in time, or answers incorrectly, the clue should reappear, and the other players should get another chance to buzz for the clue.

6. The host's side should automatically track player points based on buzz data and correct/incorrect rulings.
