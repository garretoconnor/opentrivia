# OpenTrivia

OpenTrivia is a dependency-free browser toolkit for building and hosting custom trivia games with friends.

## Run locally

```sh
npm run dev
```

Then open <http://localhost:4173>.

## Verify

```sh
npm test
npm run build
```

Authored games are saved in the browser. Boards and complete games can also be imported and exported using the JSON format in [`spec_v0_1.md`](spec_v0_1.md).
