1. Users should be able to publish games to a public listing, stored in D1.

2. Users should be able to select games from the listing to play.

3. After playing a game, users should be able to give it a thumbs up or down.

4. The listing should display games as cards, with a hero image, a title, the score (thumbs up minus thumbs down), weekly plays, and the difficulty.

5. The difficulty should be displayed as a green circle, a blue square, or a black diamond.

6. Users should be able to upload hero images when creating a game.

7. Boss boards should not have a point value, as they are wager based.

8. Users should be able to add images when creating clues.

9. Users should be able to select a game from the listing and host it for their friends.

9a. When hosting a game, users should get a unique code to share with their friends to connect.

9b. There should be a simple and clean mobile-friendly page for players to input the room code and join a friend's game.

9c. Rooms should be ephemeral. When the host closes the room, it should cease to exist.
